# Dénicho — Vision

## Pourquoi ce projet

Alexis connaît le métier de revendeur de l'intérieur (BCT_Store) : sourcing eBay/friperies, marque premium, marge cible. Le point de douleur le plus fort et le moins bien résolu par les outils existants, c'est la peur d'acheter un faux — surtout sur des marques très contrefaites comme Stone Island.

## Positionnement

Dénicho n'est pas "encore un tracker de marge Vinted". C'est l'outil de confiance du revendeur : avant d'acheter, avant de revendre, on vérifie.

## Vision long terme (V3+)

- Devenir la référence pour la vérification d'authenticité côté revendeurs particuliers (pas seulement les gros comptes pro)
- Construire une base de données communautaire de points de contrôle par marque, alimentée par les retours utilisateurs
- Étendre au-delà du textile si le modèle marche (sneakers, sacs)

## Ce que Dénicho n'est PAS

- Pas un service d'authentification certifiée (type Entrupy) — pas de responsabilité légale sur le verdict
- Pas un outil d'automatisation de publication en masse (ce n'est pas notre différenciateur, les concurrents le font déjà bien)

## Ton et marque

- Direct, utile, pas de blabla — cohérent avec le positionnement ZeroToFirst
- Communication qui parle à un vrai revendeur, pas à un investisseur
